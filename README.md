# Manory's Restaurant

An archived website for Manory's Restaurant in Downtown Troy, NY.

This was a first-semester freshman project at Rensselaer Polytechnic Institute (RPI) in Fall 2000, made for a class assignment to create a marketing page for a business in Downtown Troy. Built with Macromedia Director, Photoshop, and a digital camera, drawing on web development experience from high school.

## Hosting

The site is deployed to GitHub Pages via a GitHub Actions workflow ([.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml)) on every push to `main`.
